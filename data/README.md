# Data

The original coursework uses 15 Excel workbooks. They are intentionally **not redistributed** in this public portfolio repository because they contain third-party financial/economic data supplied with the course/textbook.

To reproduce the analyses, place the original files in `data/raw/` using exactly these filenames:

- `d-3stocks9908.xlsx`
- `m-gm3dx7508.xlsx`
- `exrate.xlsx`
- `m-dec12910.xlsx`
- `d-ibm3dx7008.xlsx`
- `waaa.xlsx`
- `wbaa.xlsx`
- `m-ew6299.xlsx`
- `q-gdpdef.xlsx`
- `m-intc7308.xlsx`
- `m-mrk4608.xlsx`
- `m-3m4608.xlsx`
- `m-gmsp5008.xlsx`
- `d-ge9808.xlsx`
- `d-csco9808.xlsx`

`data/raw/` is ignored by Git. Scripts are designed to be run from the repository root.
